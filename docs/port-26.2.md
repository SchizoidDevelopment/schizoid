# Schizoid: порт на Minecraft 26.2

**Основной `assemble` завершился успешно. Русские шрифты и Rear View реализованы; отдельный выпускной JAR прошёл standalone-проверку в TEMP на Windows x64/OpenGL, включая flat-мир и регрессии toggle/resize/F5 с exit 0. Диагностический smoke с Sodium 0.9.2 после исправления прошёл с exit 0; standalone-проверка выпускного JAR с Sodium ещё выполняется. Это не подтверждение совместимости полного модпака. Полный модпак и все модули по отдельности не проверены; изменения исходников ещё не закоммичены.**

Исходная версия — Minecraft 1.21, upstream `ea2a0a`.
Рабочая ветка — `port/minecraft-26.2`.

## Ограничения

- Проверенная и поддерживаемая платформа этой сборки — Windows x64/OpenGL. Vulkan, Linux и macOS не поддерживаются этой нативной сборкой; результаты на них не заявляются.
- Существующие модули сохраняем; не подменяем их заглушками ради зелёной сборки.
- Ориентир совместимости — установленный пак Dawn / Fabulously Optimized.
- Исходный профиль, его миры, конфиги и моды не изменяем.
- Проверка — сборка и реальный запуск, без добавления автотестов.

## Текущее состояние

- Gradle и Loom запускаются на Java 25, подготовка Minecraft 26.2 проходит.
- Access widener переведён в namespace `official`, реальные имена проверены через `javap` клиентского JAR 26.2.
- Shaded JAR собирается напрямую: в 26.2 нет этапа `remapJar`.
- Полные `compileKotlin compileJava` и `assemble` основного проекта завершились успешно 14 ноября 2026; результат — `build/libs/schizoid-0.1.0+26.2.jar`.
- Итоговый выпускной JAR SHA-256 `32BEB03EAC58DADC153DAF01441937A06275FE4D65F81809A250C7401F5575F9` прошёл standalone-проверку с Sodium 0.9.2 в отдельном TEMP-окружении: `codeSource` указывал на JAR, а не каталоги классов Gradle. Тот же артефакт прошёл отдельный standalone-запуск без Sodium, также exit 0. На итоговом vanilla-снимке main red=73.48%, blue=0%; rear blue=50.06%, red=0%.
- Kotlin client entrypoint, синхронная инициализация ImGui и регистрация 51 фичи проверены запуском. Регистрация не означает отдельную проверку поведения каждой фичи.
- Rear View теперь использует отдельные GameRenderer/LevelRenderer/LevelExtractor, независимую камеру и render target. Проход выполняется до основного, tracking sets копируются, dirty updates перенаправляются, Fabric contexts согласованы со вторичным renderer.
- Тестовый helper создал отдельный flat-мир: красная стена впереди и синяя сзади. Основной screenshot: red=298031, blue=1823; rear-target: red=0, blue=175477. Реальная обратная сцена подтверждена, не заглушка.
- Регрессия disable/enable, resize 854×480→1000×600 и переключения F5 завершилась exit 0; rear-target после неё: red=0, blue=257645. Закрытие сервера и клиента прошло штатно. Helper находится только в диагностической копии, в выпускной JAR не включается.
- Снимок финальной проекции мира захватывается отдельным mixin после эффектов камеры. Дополнительная коррекция проекции Sodium для заднего прохода включена и прошла standalone smoke. Известное ограничение Sodium: параметры fog для подготовки видимости берутся от основной камеры; ситуации с разными средами передней/задней камер не проверены. Скриншот глубины использует reversed-Z формулу 26.2, которая предполагает стандартную перспективу и диапазон глубины.
- Русские шрифты включены в основной проект: Latin+Cyrillic для Open Sans, Cyrillic merge к League Spartan, отдельный FontAwesome. В standalone-проверке выпускного JAR прошли assertions наличия кириллических глифов; `findGlyphNoFallback` подтвердил А, я, Ё, ё. Отдельные JNI-тесты проверили весь русский алфавит, иконки, два контекста и повторный Build.
- Исправленный imgui-java binding и Windows x64 DLL собраны начисто. Исходники, патчи и лицензии — `vendor/imgui-patch`; DLL SHA256 `6D65E403C1C1392D8BE9F0A0C937C8AB38AF4C86482D72129D6D2A5484ECBA4D`. Shadow JAR содержит ровно один ImFontAtlas и одну соответствующую DLL.
- Поддерживаемая нативная платформа этой сборки — Windows x64, OpenGL. Linux/macOS явно отклоняются, не используют несовместимые штатные natives молча. Проверен кириллический TEMP-путь. Не проверены non-BMP пути, native OOM, произвольные внешние TTF; исправленный путь — только file overload со встроенными доверенными шрифтами.
- Тесты используют отдельные `user.home` и gameDir; реальные миры и аккаунты не использовались. Vanilla Rear View показал противоположную стену по пикселям, а standalone-сценарий flat-world/toggle/resize/F5 завершился exit 0. Полный пользовательский модпак и каждая игровая функция отдельно пока не проверены.
- Диагностический smoke с Sodium 0.9.2 после исправления прежней ошибки `Global terrain uniforms not updated` прошёл: toggle/resize/F5, exit 0; rear-target 1000×600 — red=0, blue=257645. Это PASS диагностического сценария, не всей совместимости Sodium. Standalone-тест выпускного JAR с Sodium также прошёл exit 0: кириллица, flat-мир, off/on, resize, F5 и штатное завершение. На строгой паре снимков main red=73.48%, blue=0%; rear blue=50.06%, red=0% (проверка перед последней коррекцией проекции); последний JAR с коррекцией также завершил smoke без ошибок. Скрытие Rear View при наличии Iris сохранено; рабочий Rear View с Iris не заявляется.
- Изменения исходников ещё не закоммичены; успешный тест относится к проверенному JAR и рабочему дереву, а не к опубликованному коммиту.
- Пути шейдеров приведены к нижнему регистру. При будущей подготовке коммита на Windows с `core.ignorecase=true` проверить `git -c core.ignorecase=false status --short --untracked-files=all`, чтобы не пропустить case-only переименования.

## Пак пользователя

Путь к модам: `%APPDATA%/.dawn/profiles/fabulously-optimized/.minecraft/mods`.
Прочитаны метаданные 72 активных JAR; два `.jar.disabled` не включались.

| Пересечение | Моды | Что проверить в игре |
|---|---|---|
| Рендер / шейдеры | Sodium 0.9.2, Iris 1.11.4, ImmediatelyFast 1.16.5 | Целевой framebuffer, восстановление GL-состояния, GUI, ESP, blur; с шейдерами и без |
| Скрытие сущностей | EntityCulling, MoreCulling, EMF / ETF, BetterBlockEntities | Отрисовка ESP и моделей, таймеры, Target HUD |
| Клиент и ввод | Dawn, SnapTap 2.0, Ixeris, Zoomify 2.17.0 | GLFW callbacks, бинды, движение при открытом меню, FOV |
| Аккаунты и чат | Dawn, NoChatReports, MoreChatHistory | Смена аккаунта, службы профиля / скинов, собственные сообщения |

Это **места возможных пересечений**, не список подтверждённых конфликтов.

В исходной папке обнаружены одинаковые ID в двух версиях:

- `betterblockentities`: 1.3.8-beta.1 и 1.3.9.
- `ixeris`: 4.6.11 и 4.6.8.

Ничего не отключали и не удаляли. До проверки пака нужно установить, какие JAR реально выбирает его загрузчик.

## Команды

```powershell
# Полная компиляция и сборка выпускного JAR; эта команда прошла в основном проекте.
.\gradlew.bat assemble --console=plain

# Зафиксировать полный SHA-256 конкретного артефакта перед повторной standalone-проверкой.
Get-FileHash -Algorithm SHA256 -LiteralPath '.\build\libs\schizoid-0.1.0+26.2.jar'

# Дополнительная диагностика Sodium/Mod Menu: smoke Sodium 0.9.2 прошёл,
# но результат не означает совместимость всех функций или полного пака.
# Запускать в отдельной копии с отдельными gameDir и user.home, не в пользовательском профиле.
.\gradlew.bat runClient -PwithOptionalMods=true

# Будущая проверка полного пака: JAR читаются из каталога пака, но gameDir и user.home
# необходимо направить в отдельное тестовое окружение. Эта проверка ещё не выполнялась.
$mods = "$env:APPDATA\.dawn\profiles\fabulously-optimized\.minecraft\mods"
.\gradlew.bat runClient "-PcompatModsDir=$mods"
```

`runClient` использует классы разработки и сам по себе не доказывает работоспособность выпускного JAR. Для повторения standalone-проверки нужен чистый TEMP-профиль Fabric с конкретным JAR, соответствующими Fabric API/Kotlin и отдельными `gameDir`/`user.home`; в логе проверяется `codeSource` из JAR. Тестовый helper flat-world/toggle/resize/F5 не входит в выпускной артефакт.

Fabric API и Kotlin из каталога пака не добавляются второй раз: используются зависимости той же версии из Gradle. Подключение пака реализовано как настройка runtime classpath; совместимость полного пака не проверена. Диагностический smoke Sodium 0.9.2 прошёл, standalone-проверка выпускного JAR с Sodium ещё выполняется.

## Продолжение

1. Дождаться результата standalone-проверки выпускного JAR с Sodium 0.9.2; не переносить PASS диагностического smoke на выпускной артефакт или полный пак. Завершить коррекцию fog/projection, затем повторить затронутые проверки.
2. Сохранить скрытие Rear View при Iris, пока отдельная реализация и её проверка не подтвердят поддержку; не трактовать скрытую фичу как пройденный тест.
3. Проверить остальные игровые модули и эффекты, смену аккаунтов/скинов, resize и освобождение ресурсов в изолированном окружении; реальные токены и аккаунты пользователя не менять.
4. После отдельных модов проверить полный Dawn / Fabulously Optimized пак в отдельном профиле; сначала установить, какие версии дублирующихся ID выбирает загрузчик.
5. Перед публикацией сохранить полный SHA-256 выпускного артефакта и логи standalone-проверки, проверить лицензии/нативную упаковку и case-only переименования шейдеров, затем подготовить коммит. Исходники пока не закоммичены.
